# ConCrunch Manager

ConCrunch Manager je webová aplikace pro správu festivalového programu a souvisejícího obsahu.

Projekt je vyvíjen postupně podle projektového plánu. Tento repozitář obsahuje průběžně zveřejňované části frontendové a backendové implementace.

## Technologie

### Frontend

- React
- Vite
- React Router
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

### Autentizace

- Google Authentication

## Stav projektu

Projekt je aktuálně ve vývoji. Jednotlivé funkcionality a související dokumentace budou do repozitáře přidávány postupně v návaznosti na realizaci projektu.
